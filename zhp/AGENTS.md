# zhp/ — 学习协作约定

> 本文件是 lux 与 dsh agent 的长期协作记忆。新会话先读这里，再读 [README.md](./README.md)。
> 仓库根 `AGENTS.md` 是项目开发规则；本文件补的是"我们一起学什么、怎么学"。

## 我们在做什么

1. **主线：陪 lux 学习 dsh 源码。** 当前工作区就是 dsh 的源码仓库。学习笔记写进 `zhp/`，一个主题一篇。
2. **暂缓：可自我修改的 agent。** 设计与约束见 [04-self-evolving-agent.md](./04-self-evolving-agent.md)，目前**不作为工作内容**——不推进设计、不改实现。实现位于 `packages/experimental/evolve/`，由另一个会话负责，不要改动。

## 怎么合作

- 中文交流。**解释优先于执行**——lux 在学，不是单纯要结果。
- 编号连续：`zhp/NN-<topic>.md`；每新增一篇，同步更新 [README.md](./README.md) 索引。
- 每篇固定头部：状态（学习中 / 草案 / 已核实 / 已实现）、日期与基线 commit、证据图例、一句话结论。
- 证据五级：**实测 / 源码 / 日志 / 二手 / 推断**。推断不得写成观测；不确定就标出来。
- 一个事实一个家：沙箱边界只写在 `03`，其他篇链接过去，不复制。
- 代码引用写成链接：聊天用 `packages/x.ts#L283`，文档用相对路径 `../packages/x.ts#L283`；不确定行号就只写文件名。
- 注意：文档预览不解析本地链接（见 `05`），链接只在聊天和 GitHub 上可点。
- 每篇结尾留"还没搞懂"，下次从那里接着挖。
- **自动提交**：文档改动完成后直接 `git commit`（`docs(zhp): ...`），不询问。只提交自己改的文件；不碰 `packages/experimental/evolve/` 等在途改动；commit 自动；push 只在明确要求时（如“push all”）。
